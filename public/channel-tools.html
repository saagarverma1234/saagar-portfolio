Xavier Foster Tools

Xavier Foster Tools is a private publishing tool used only by the owner of the Xavier Foster, Motor Lineage, Wild Ranks, Bump Theory, Doc & Bean, StackedClassics, What If Maxed and Five Second Fix YouTube channels to manage those channels.

With the owner's permission, it uses the YouTube Data API and YouTube Analytics API to:

  • upload the owner's own videos and captions to the owner's own channels,
  • edit titles, descriptions, tags and thumbnails of the owner's own videos,
  • read view counts and analytics for the owner's own channels.

Developed and used by Saagar Verma. It is not offered to the public and does not access anyone else's account.
