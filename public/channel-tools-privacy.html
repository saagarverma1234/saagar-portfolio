Privacy Policy

App: Xavier Foster Tools · Last updated: 17 October 2026

Who uses this app

Xavier Foster Tools is a private tool used only by its owner, Saagar Verma, to manage the owner's own YouTube channels. It is not offered to the public.

What data it accesses

When the owner signs in with Google, the app requests access to YouTube (youtube.force-ssl, youtube.upload) and YouTube Analytics (yt-analytics.readonly) for the signed-in channel. It uses this access only to upload the owner's own videos and captions, edit the metadata and thumbnails of the owner's own videos, and read statistics and analytics for the owner's own channels.

How data is stored

Sign-in tokens and downloaded statistics are stored only on the owner's own computer, in files readable only by the owner. Nothing is stored on any server operated by this app.

Sharing

Google user data is not sold, shared with third parties, used for advertising, or used to train AI models. Xavier Foster Tools' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Local tokens are deleted when they are no longer needed.
